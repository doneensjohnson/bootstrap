# bootstrap

What challenges did you face when refactoring your code to use Bootstrap?
  I continue to run into positioning challenges. Getting my content centered on the page has been a struggle with css and now bootstrap. Once I understand why the positioning codes are not working within my codes, I will be able to properly position my content.

How did using Bootstrap utility classes and components simplify your styling process?
  Using bootstrap was considerably simpler because I was able to add prebuilt codes right within the class tags. I did not have to create additional containers and figure out if the naming was consistent as with moving it over to css. 

In what scenarios might you choose not to use Bootstrap and write custom CSS instead?
  When I cannot find the appropriate bootstrap code, I will elect to use css instead. I will need to build my own library of codes that I know I will regularly use and know how it looks on the page so I am not having to play around with the previews as often.
